# 全聯消費明細抓鬼系統 V1.0

上傳全聯 App（PX Pay）消費明細截圖 → 手機上 OCR 辨識 → 逐筆核對 → 存入本機資料庫 → 自動比對同一商品上次與本次價格。

## 開啟方式

1. **網址（任何人都能直接開，不用登入）**：https://superbigrabbitrabbit-coder.github.io/px-ghost/
   用 iPhone 的 Safari 開啟，可按「分享 → 加入主畫面」當成 App 使用。
2. **claude.ai 版**：https://claude.ai/artifact/5FLr7KrGXvnjSb4FaYfEEt
3. **本機測試**：在這個資料夾執行 `npx http-server -p 8765 .`，瀏覽器開 `http://127.0.0.1:8765/`。
   直接雙擊 `index.html`（file://）時 OCR 無法運作，必須透過網址開啟。

不同網址的資料**互不相通**（瀏覽器依網址分開保存），換方式時請用「匯出 JSON 備份 → 還原備份」搬資料。

## 價格規則摘要

- 明細「金額」是整列小計；可比較價格＝每件實付均價＝金額 ÷ 數量（計算值）。
- 價格差額＝本次 − 上次；漲跌百分比＝差額 ÷ 上次 × 100%，四捨五入到小數 2 位。
- 「上次」＝同一商品、在另一筆較早交易中的最近一次有效紀錄。
- 無法比較：缺日期、缺數量、缺金額、金額 ≤ 0、數字待確認、標示價格口徑不明。
- 商品比對：逐項比較條碼、名稱、品牌、規格（容量／重量／入數）與價格。
  - 條碼相同直接歸入；條碼、品牌或規格兩邊都有且不同，一律分開。
  - 明細沒有容量時，與上次價差超過 30% 視為「可能是不同容量」，先交給使用者確認，不算漲跌。
  - 同名商品有多種容量且都設定好容量時，依價格對應到價格相符的那個容量，並在明細上註明「依價格對應」。
  - 相似名稱交給使用者確認，待確認頁會列出每一項的比對結果。
- 原價只在截圖有顯示時使用，不自行推算；整筆折扣不自行分攤，只提示。

## 資料保存

資料只存在開啟網址的那個瀏覽器（IndexedDB）。清除網站資料、換手機、無痕模式都會看不到資料；Safari 也可能清掉久未開啟的網站資料。請定期在「匯出資料與備份」匯出 JSON。
